# ToDo List

Лабораторная работа №2 по веб-программированию.

Веб-приложение ToDo-лист на чистом JavaScript без фреймворков.

**Сайт:** https://enfantrich3.github.io/WebLab2/

## Возможности

- добавление, удаление и редактирование задач (текст и дата)
- отметка задачи как выполненной
- сортировка задач по дате
- фильтрация по статусу (все / невыполненные / выполненные)
- поиск задач по названию
- сохранение задач в localStorage
- изменение порядка задач с помощью drag-and-drop

## Структура

- `index.html` — только базовый каркас и подключение скрипта
- `app.js` — создание всех элементов страницы и логика приложения
- `style.css` — стили и адаптивная вёрстка (flex, grid, media-запросы)
